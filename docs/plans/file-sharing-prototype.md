# 文件分享交互原型

日期：2026-10-17。状态：已实现可交互原型，待 UI 评审；正式功能参数待确认。

## 目的与范围

在现有 Paste UI 内评审文件分享的创建、接收、错误恢复和后台管理流程。正式功能方案见 [file-sharing.md](./file-sharing.md)。原型入口为 `/prototype/file-sharing`，不接入真实文件 API。现有文本分享页同步精简说明文案。

文件只保留在当前页面内存中，刷新后清空。上传进度和服务端错误采用模拟，下载仅使用本地选择的文件或内置示例。页面顶部明确显示演示边界，生成的链接只用于预览原型接收页，不能作为真实文件分享链接。

## 视觉约束

- 以当前 `app/page.tsx`、`app/globals.css` 和业务组件的实际样式为准；设计文档中的旧动效不重新引入。
- 保留现有 Logo、Geist / Geist Mono、黑色背景、琥珀色强调、细边框和圆角。
- 创建页保留背景网格、900px 外层、700px 主内容区和三列分享选项。
- 复用现有 Button、Input、Select、Dialog 和编辑器；不修改 `src/components/ui/*`。
- 接收页和后台不使用首页网格。手机选项纵向排列，文件名能够换行，操作无需依赖拖拽或悬停。

## 交互约束

1. 创建页默认选择文件模式；可以切换文本模式，并保留两种模式已经输入的内容。
2. 文件支持选择和拖拽，每条分享一个文件。拟议上限 10 MiB，空文件允许分享，超限或多文件显示明确错误。
3. 文件选项为可选密码、有效期和下载机会。默认有效期一天，最多七天；文本仍展示原有选项。
4. 选择文件、模拟上传、取消、保存、成功弹窗、失败与重试都可操作。100% 上传不等同于保存完成。
5. 成功弹窗显示文件名和原型链接，提供复制、预览接收页及继续创建。
6. 接收页提供可下载、密码保护、已过期和次数耗尽场景。密码错误不能显示文件名或消耗下载机会。
7. 点击下载才消耗机会，重复点击不重复启动同一次操作。用尽后显示清楚提示；不声称浏览器已成功保存。
8. 后台预览支持类型筛选、详情和确认删除，文件大小与存储用量随演示数据变化。

## 实现与验收

页面放在 `app/prototype/file-sharing/`，组件及就近测试放在 `src/components/file-sharing-prototype/`。使用已有 React、Radix、Lucide 和 Tailwind，不增加依赖。

- 组件测试：文件边界、模式切换保留输入、上传取消/失败重试、密码和次数、后台筛选/删除。
- 实际执行 `pnpm test`、`pnpm lint`、`pnpm exec tsc --noEmit --incremental false` 和 `pnpm build`，记录结果与限制。
- 浏览器实测完整流程、键盘操作、窄屏长文件名、减少动态效果，以及 320/768/1024/1440px 宽度。
- 正式上传、加密存储、代理限制、清理任务、杀毒和真实后台持久化不属于交互原型的实现范围。

## 体验入口

本次预览服务：[打开交互原型](http://127.0.0.1:3101/prototype/file-sharing)。这是本机地址，不是线上部署。

在仓库内运行 `pnpm dev` 后也可以访问 `http://localhost:3000/prototype/file-sharing`。点击“试用示例”，或者选择自己的小文件；顶部切换创建、接收和后台场景。接收页下拉框可演示密码、过期和次数用尽。

原型初始选择 3 次下载机会，方便体验后再切换其他选项。刷新后所有演示数据重置。原型链接不能跨设备分享浏览器内文件。

## 实际验证记录

环境：Node 24.19.0、锁定依赖、Chromium。生产构建与迁移使用独立临时源码副本和测试库；原型没有写入项目业务数据库。

| 实际执行命令 | 结果 |
| --- | --- |
| `node node_modules/vitest/vitest.mjs run` | 18 个文件、135 个测试通过，含 15 个原型测试。旧 Motion 测试有减少动态效果提示，无测试失败。 |
| `node node_modules/eslint/bin/eslint.js` | 通过。 |
| `node node_modules/typescript/bin/tsc --noEmit --incremental false` | 通过。 |
| `node scripts/migrate.mjs`，隔离目录 | 正常应用现有迁移。 |
| `pnpm --config.verify-deps-before-run=false build`，隔离目录 | 最终默认 Turbopack 构建通过，类型检查与 13 个静态页生成通过。原型为独立静态路由。 |
| `HOSTNAME=127.0.0.1 PORT=3101 node server.js`，standalone 目录 | 实际运行生产产物并完成浏览器验证。 |

首次在全新临时目录直接构建时，现有数据库模块被多个构建 worker 同时初始化，出现 `SQLITE_BUSY`。执行项目现有迁移初始化测试库后重试成功；没有修改数据库模块或降低构建检查。该首次初始化问题属于现有构建链，仍未在本轮修复。

浏览器实际验证：

- 选择本地文件、拖拽文件、多文件拒绝、文本/文件切换保留内容、上传与保存后弹窗。
- 复制被拒绝时显示可恢复的错误；验证期间拦截了剪贴板调用，没有修改系统剪贴板。
- 错误密码不显示文件名或消耗机会；正确密码下载示例文件。
- 实际下载 1,622 字节的本地中文长文件名文档，与所选原文件逐字节一致；最后一次下载后显示次数用尽，后台同步状态。
- 键盘操作场景页签和次数选项。减少动态模式下上传图标的计算动画为 `none`。
- 创建/接收页在 320、768、1024、1440px 宽度没有文档横向溢出；390px 长文件名可以换行，文件扩展名正常显示。
- 后台类型筛选、详情、取消删除、确认删除可操作；删除大文件后模拟占用从 2.4 MiB 更新为 1.6 KiB，删除当前分享后接收页显示“分享已删除”。
- 上述文件流程没有任何 `/api/` 请求，文件只在浏览器内存中。未验证真实上传、安全控制、磁盘清理、Docker/Nginx 或 Safari/Firefox。
