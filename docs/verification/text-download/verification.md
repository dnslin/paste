## 浏览器验收

浏览器运行构建后的 standalone 产物，使用隔离 SQLite、随机本地密钥和测试管理员。未复制项目原有数据库、环境文件或生产密钥。当前三份改动后的运行源文件与构建副本逐一比较一致。

先通过正式首页创建受密码保护、允许查看 3 次的 JSON；其他格式通过正式创建 API 产生，不直接写库生成正文。预览初始化时，macOS `/tmp` 符号链接导致迁移脚本入口未执行，曾出现缺表；随后显式调用原迁移函数完成隔离数据库初始化，全部业务验收在初始化成功后进行，未修改迁移脚本。

| 场景 | 实际结果 |
| --- | --- |
| 未领取的受限/受保护文本 | 页面 GET 不包含正文；没有下载入口，次数保持 3 或 1 |
| 密码错误 → 正确密码 | 错误返回可重试提示，次数仍为 3；正确领取后为 2。连续下载两次后仍为 2，页面 verify 请求数保持 2（一次错误、一次正确） |
| 其他请求耗尽次数 | 其他两次真实领取后剩余 0；当前页仍可下载已取得的 JSON，内容一致；新页面显示“查看次数已用完”，没有下载入口 |
| 最后一次 SQL | 显式领取把 1 扣至 0；Tab 聚焦下载，Enter 发起下载。连续保存两份 SQL，只有一次 verify；刷新后不可领取 |
| 无密码、不限次数 | 直接显示正文，无 verify。JSONC 页面刷新后仍直接可下载 |
| 分享到期 | YAML 通过正式 API 创建并成功显示后，只把这条隔离记录的 `expires_at` 调至过去。旧页下载字节不变，新页面显示“内容已过期” |
| 分享删除 | 通过正式后台登录和 DELETE API 删除当前隔离测试文本。旧页仍能保存已取得的内容，新页面显示“内容不存在” |
| 本地文件准备失败 | 临时让浏览器 `URL.createObjectURL` 抛错，显示“下载未能发起”，正文和复制仍可用；恢复原 API 后重试成功，verify 数仍为 0 |
| 原文与后缀 | JSON、JSONC、SQL、YAML、TOML、INI、Nginx 共七种后缀及其他语言 `.txt`，实际文件名和 UTF-8 字节均正确，无新增 BOM；注释、缩进、中文、特殊字符、空行、末尾换行及 CRLF 保持 |
| 显示换行 | 切换“长行换行”后保存内容不变；320px 不换行时，代码滚动区宽 270px、内容宽 1214px，页面宽仍为 320px |
| 响应式布局 | 1440/1024/768/390/320px 的文档宽度都等于视口宽度；复制和下载按钮高 44px，均在页面范围内 |

到期场景的时间调整，以及本地失败的客户端故障注入，都是受控测试设置，不代表自然等待到期或浏览器实际故障。其他领取、密码、下载与删除使用正式业务路径。具体请求数、文件名、字节比对及尺寸见 [browser-evidence.json](browser-evidence.json)。
